# Memory Passport — local edition

Native iPhone/iPad notebook for carrying user-approved context between AI conversations. No dependencies, backend, analytics, account connection, model calls or payments. Text import, project filtering, search, edit/delete, atomic protected-file persistence, context copy and export.

Generate: `xcodegen generate`. Build the MemoryPassport scheme for iOS Simulator. Bundle identifier is provisional and unregistered.

This is the first local version, not a submitted App Store product. Automatic extraction, cross-device sync and provider integrations are not implemented. Proposed paid tier: €7.50/month only when an ongoing paid service exists; no paywall in this version. Native subscriptions require StoreKit configuration and review. A release also needs app icon, privacy policy, metadata, physical-device checks, signing and App Store Connect setup. No new paid services may be enabled.
