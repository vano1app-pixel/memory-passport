# Memory Passport

For people moving work between AI assistants. Primary task: save a fact, choose a project, and copy a portable context brief. Alternatives are notes and manually repeating context. No account connections are implied.

Art direction: a quiet field notebook, warm paper, forest-green ink, serif title and native controls. A ruled list carries the product rather than a marketing hero. iPad uses a readable centered notebook; iPhone keeps the same task accessible at large type sizes.

All content starts empty. Imports are reviewed as editable text before saving. No automatic factual extraction or model calls. Storage remains on this device; export is explicit. No live subscription or cloud sync in version 0.1.
